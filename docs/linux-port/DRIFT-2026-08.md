## B. Shared-CLI contract changes (bite at the next merge)

These live in `CLI/` we vendor; they don't affect today's port but define
the next merge's checklist:

1. **Compile breaks:** `CLISocketPathResolver` became an instance struct
   returning `CLISocketPathResolution` (every caller changes);
   `SSHPTYAttachExitCode.swift` moved to `Packages/macOS/CmuxFoundation`
   (a `CLI/`-only vendoring breaks).
2. **Fail-closed `resolveSurfaceId`:** every explicit surface handle is
   validated against a live `surface.list` — our `surface.list` must echo
   `id`/`ref`/`index` with full fidelity or close/respawn/kill-pane start
   hard-failing. `close-surface --surface` without `--workspace`/`--window`
   is now a usage error.
3. **Live-probing socket discovery:** implicit resolution connects
   (200 ms-class non-blocking probe) before selecting; stale files are
   skipped; `--socket`/env paths are pinned and never rerouted. Verify our
   port unlinks its socket on clean exit and that our default path is in
   the resolver's candidate list.
4. **New verbs to route or reject cleanly:** `restore` (needs A10's
   `restore_record`; waits up to 45 s for a socket), `mosh`/`mosh-tmux`,
   `comments list`, `simulator`/`ios` (29+ methods — want a clean
   "unsupported on this platform" rather than raw method-not-found),
   `iroh-diag` (v1), `coderouter` (no socket).
5. **Fail-open params the CLI now sends** (server silently ignoring =
   silent feature loss): `profile` (pane.create), `reply_shape`
   (notifications), absolute `zoom`, `caller` (system.identify/tree/
   memory), `terminal_transport`/`terminal_profile` (remote), structured
   `launch_command`+`permission_mode` (surface.resume.set),
   `close_workspaces` (group delete — here silent-ignore is *destructive*,
   see A1).
6. **identify multi-stage caller resolution:** malformed caller
   `surface_id` triggers 2–3 identify round-trips (hook latency); keep our
   caller block UUID-clean.
7. **Feed classifier:** Codex/Gemini permission prompts became
   `nativeApprovalPrompt` (notify_target_async raise / clear_notifications
   clear); kimi hook config moved `.kimi-code/`→`.kimi/` (our resume
   record matching should tolerate both); `--fork-session` sniffing
   deleted (Claude fork identity now comes only from authoritative
   `SessionStart`); `isCmuxClaudeCommandShim`→`isCmuxAgentCommandShim`.
8. **`workspace-group delete` CLI default flip** (sends `ungroup` bare;
   `--close-workspaces` for destructive) — pairs with A1.

## C. Surface drift (config, shortcuts, panels, palette)

- **Schema +5 keys:** `app.focusHistoryIncludesPanesAndTabs`,
  `notifications.paneFlashColor` (attention blue now themable — pairs
  with our GNOME-accent deviation), `browser.defaultZoomLevel`,
  `mobile.artifactFolderAccess` (+`mobile` object). `shortcuts.when` +
  `simulatorFocus` key. `terminal.sessionContentMaxWidth` ceiling removed.
- **Hibernation semantics:** `enabled:false` no longer means never —
  critical memory pressure still hibernates (#9090); renderer-reclaim
  defaults tightened (`rendererIdleSeconds` 30→5, `maxWarmRenderers`
  12→1).
- **Shortcut registry 125 → 145** (+20): six move-surface-to-pane actions
